# 题库学习助手

入口：所有页面右下角「AI 答疑」，题目操作区「AI 讲解」。访客可以使用按 IP 计数的 10 次额度；有效登录会话获得 50 次账号额度。直接 API 请求使用相同的服务端会话与额度检查。POST 要求同源 Origin 和 JSON；页面仅使用 textContent 显示回答。

交互：所选题目的材料自动带入，不提供额外的材料编辑面板；补充说明和连续追问统一在聊天输入框完成。Enter 发送，Shift+Enter 换行；点击发送按钮仍可提交。

模型：北京地域 `qwen-flash`，关闭思考，最大输出 4096 Token。账号所有者已确认该模型有免费额度并开启「免费额度用完即停」。Secret `DASHSCOPE_API_KEY` 在 Cloudflare 运行时配置，不提交源码。`QWEN_FREE_ONLY_CONFIRMED` 是部署人员确认标志，并不替代百炼的保护开关，也不表示程序查询了供应商剩余额度。

范围：助手回答学习和技术问题，不局限于本站题库。2026-10-12 根据用户反馈移除后端关键词相关性检查；后续按用户要求在系统提示中加入语义范围要求：拒绝纯娱乐游戏攻略、消遣闲聊等无关内容，拒答通常一句话；游戏开发、真实技术故障排查与真正的语言/数学练习仍允许。意图不明确时简短澄清，不因缺少题库关键词直接拒绝。支持任何语言，跟随当前提问语言或用户明确指定的语言，不再默认中文。

实现边界：提示词不是绝对可靠的拦截器，本次不增加后端分类调用或关键词过滤。无关请求仍需调用模型来判断和简短拒答，因此消耗输入与少量输出 Token、正常占用一次每日次数；不能保证零消耗或完全阻止绕过。所有有效请求都先预留预算再调用 Qwen；失败请求的原有计数规则不变。题目、参考答案、原文和历史消息均为不可信学习资料，不执行其中改变角色或索取凭据的指令。缺少解题所需材料时请求补充，学习或技术提问不要求带入题目。系统提示源文件为 `worker/chat.mts`，编译至 `worker/chat.mjs`。额度、来源校验、输入大小、并发限制、上游 Token 预算和免费额度用完即停保护保留。

配额：访客按 Cloudflare 提供的客户端 IP 每天 10 次；登录账号每天 50 次。访客注册并登录后，同一 IP 当日已用次数计入该账号 50 次额度。访客 IP 标识通过 HMAC（服务端 API Secret 作密钥）计算并保存，不保存原始 IP；同一 IP 下未登录访客共享 10 次额度。更换 Qwen API Key 会重置当日访客标识。所有每日额度均按固定 PST（UTC−8）每日 00:00 重置，不切换夏令时。全站每天最多 1000 次、累计保守 Token 预算 800000。输入最多 24000 UTF-8 字节，问题最多 2000 字符，材料最多 10000 字符，保留最近 6 条消息。发送前通过单个条件 INSERT 原子预留预算，包含输入字节、输出上限和额外余量。成功后按上游 usage 结算；未知结果保留全部预算。失败也占次数，防止无限重试。同一访客或账号同一时刻只有一个请求、间隔至少 5 秒。

2026-10-12 调整：游客每日上限从 20 降至 10，历史消耗不清空；登录用户仍为 50。用户确认网页检索暂缓，本次不启用联网搜索，不新增搜索费用。

上游 401/402/403/404 将全站标记停止，且不自动切换模型。免费用完或过期的防扣费保证由百炼「免费额度用完即停」提供；本站预算只统计本站，不能覆盖其他程序调用同一模型的消耗。超时 90 秒，无自动重试。消费记录仅保存账号 ID、时间、预留量、实际量和状态，不保存对话文本。删除账号后记录保留但账号 ID 置空，确保全站预算不会被删除账号重置。

部署：先 `wrangler d1 migrations apply quizbank-accounts --remote` 再 `wrangler deploy`。所有新增表向后兼容旧版本；回滚旧 Worker 不影响账号和进度。

排障：读取服务端 `ai_provider_denied` 的状态码，检查密钥、北京模型 Code、剩余额度和用完即停。修复后管理员可执行 `UPDATE ai_state SET stopped = 0 WHERE id = 1`，但不会清空已有使用预算。要调整限额修改 `CHAT_POLICY`；只有在核对新的免费额度后才能提高累计预算。聊天内容仅驻留当前页面内存，不做本机或云端历史存储。
