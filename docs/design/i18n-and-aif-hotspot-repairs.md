## AIF 匹配题

`site/assets/aif-hotspots.json` 是 32 道 HOTSPOT 题的结构化补录。项目与选项从已有 OCR 文本清理出来，原题干和解析保留；25 道答案来自已有解析，不宣称它们是 AWS 官方考试答案。第 114 题的步骤顺序同时参照 [AWS ML lifecycle](https://docs.aws.amazon.com/wellarchitected/latest/machine-learning-lens/machine-learning-lifecycle.html)。

- 每个项目使用原生下拉框，键盘和手机均可操作；顺序题不允许同一选项重复。
- `A>B>C` 为一个有序答案，复用现有填空判分与 `quiz:aws:aifbank:NN` 存储，因此沿用现有账号同步路径。
- 未选完不能提交；原生下拉框的 Enter 不误触全局判分。
- 支持确认、查看答案、重做、下一题、清空和刷新恢复已完成的作答。
- 同步下载版 Markdown；`quiz_kit/hotspot_sync.py` 幂等更新，生成器也使用同一数据。
- 原资料没有可核对答案：185、188、191、229、309、313，展示选项但不判分。
- 第 245 题的解析涉及 Fairness，但 OCR 选项没有可靠的相应项目；保留能辨认的选项并标记来源冲突，不推测完整选项或启用判分。
