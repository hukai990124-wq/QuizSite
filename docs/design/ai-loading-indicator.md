# AI 请求加载指示

发送问题后，状态文字左侧显示小型旋转圆环，沿用深蓝主题。由 TypeScript `setBusy` 统一设置请求状态、对话框 `is-thinking` 类和表单 `aria-busy`；回答成功或发生错误后立即停止，不等待额度查询结束。不会显示模型的内部推理过程。

圆环通过 CSS 伪元素绘制，不干扰三语文字切换、不新增图片或动画依赖。状态文字仍使用 `role=status`，装饰圆环不提供多余播报。在 `prefers-reduced-motion: reduce` 下显示静态圆环，停止旋转。

浏览器验证使用延迟的模拟 AI 请求，覆盖成功、503 失败、再次发送和减少动态效果设置，不消耗线上模型额度。无 API、额度或登录逻辑调整；可回滚本提交恢复文字提示。
