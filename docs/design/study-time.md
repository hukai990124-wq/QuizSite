# 今日学习时间

2026-10：另行加入[账号周学习时长](weekly-study-time.md)。下述“仅本机、不上传”仅描述本地每日计时：其存储键、日期规则和主页标签不变。登录后，共享计时器另外向周统计模块提供短暂前台区间，周统计保存至账号，按固定 UTC−8 周一零点清零。游客每日时长不迁入账号。

主页标题下用 14px 普通文字显示「今日已学习 HH:MM:SS」，支持英文、日文随界面切换。不在题库子页面显示，但所有已接入共享 back-to-top 模块的页面都累计前台可见停留时间。没有“点击或答题才能计时”的要求。

日期按浏览器本地时间每日零点切换，独立于 AI 次数的 UTC−8 重置规则。切换到其他网站标签、最小化或隐藏页面后暂停，回来继续。每秒保存至 `quizsite:study-time:v1` localStorage；刷新、关闭后再打开、题库与主页之间导航均延续当日记录，最多可能丢失最后约一秒。不统计关闭网站的时间，也不追补上线前的停留时间。

数据仅保存在当前浏览器，不上传、不跨设备同步、不混入答题进度；清空浏览器站点数据会清除计时。存储不可用时保留当前页内存并通过文字 title 说明限制。

跨标签页通过 Web Locks 串行更新，保存时间区间并集，同一浏览器多个可见窗口不会翻倍计时。没有 Web Locks 的旧浏览器只由获得焦点的页面更新；计时延迟超过5秒时只计最后5秒，避免设备休眠期间虚增。该计时是浏览器端学习辅助显示，不是防篡改的考勤记录。

验证：时间格式、区间重叠、暂停间隙、本地午夜、错误数据与时钟回拨的单元测试；浏览器覆盖主页独占显示、做题时持续累计、刷新、隐藏暂停、跨标签页、三语和手机宽度。没有调用 AI 或新增服务端存储。

实现参考：[Web Locks](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)、[Page visibility](https://developer.mozilla.org/en-US/docs/Web/API/Document/visibilitychange_event)。
