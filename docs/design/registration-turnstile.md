# Registration-only human verification

Owner approved Turnstile on registration only. Login, existing sessions, password rules, progress and AI quotas remain unchanged. Require `TURNSTILE_SITE_KEY` (public runtime variable) and `TURNSTILE_SECRET_KEY` (encrypted runtime Secret). Incomplete configuration blocks registration with 503, never bypasses verification; login continues normally. Preserve dashboard variables during deployment. Never read/log/export the secret value.

GET `/api/auth/registration-config` returns only `{configured,siteKey}` with no-store/security headers. POST `/api/auth/register` retains same-origin JSON, size bounds, credential validation and existing shared auth rate limiting; requires `turnstileToken`. Verify with the fixed Cloudflare Siteverify HTTPS endpoint before password hashing or writes; require `success === true`, exact request hostname and `action === register`. Empty/oversized/rejected/expired/replayed tokens: 403. Missing configuration, timeout, malformed/unavailable provider: 503. No retries or raw upstream errors. Cloudflare enforces token expiry and single use; no new token/IP logs or persistence.

Only selecting registration loads the Cloudflare widget. Managed widget with register action; three-language status, compact responsive layout, expiry/error/retry handling. Closing/switching to login removes widget and clears token; asynchronous completions after removal cannot restore it. Every failed registration refreshes the one-use token; success clears it. A blocked script/provider must not block login. Public privacy notice links to Cloudflare's Turnstile privacy addendum.

Tests: server fail-closed cases and host/action validation; route guard before database writes; existing account/session tests with mocked provider; isolated browser script/config failure, retry/expiry, mode/close/language transitions and registration payload. No real account creation or AI calls in browser tests. `pnpm test`, `pnpm typecheck`, browser regression and floor guard before release. Real human challenge cannot be solved by automated test; owner confirms a successful real registration after deployment. Rollback is frontend/backend code revert, with no schema migration.
