# Additional listening audio provenance

Sets 05 and 06 are original/adapted TOEIC-style practice, not ETS test recordings.
All speech is synthetic. Voice assignment is recorded per segment in
`data/extra-audio-jobs.json`; file hashes and generation engines are recorded in
`data/audio-manifest.json`.

## Test 05 — historical Piper version (replaced 2026-10-15)

Test 05 now uses Kokoro with the same settings as Test 06 below. Its previous
Piper attribution is retained here for historical provenance; no current
Test 05 MP3 is generated by Piper.

American male voice: Piper `en_US-ryan-medium`, a single-speaker US English
model. The published model repository is MIT licensed.

British female voice: Piper `en_GB-vctk-medium`, speaker `p225` (speaker ID 107).
Model/configuration: https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_GB/vctk/medium

The published model repository is MIT licensed. The model card identifies the
VCTK corpus under CC BY 4.0 and states that it was fine-tuned from Lessac medium.
We do not distribute either model, training recordings, or runtime in the
website. Model file hashes are retained in the audio manifest.

VCTK attribution: Yamagishi, Junichi; Veaux, Christophe; MacDonald, Kirsten (2019).
CSTR VCTK Corpus: English Multi-speaker Corpus for CSTR Voice Cloning Toolkit
(version 0.92). University of Edinburgh, Centre for Speech Technology Research.
https://doi.org/10.7488/ds/2645
License: https://creativecommons.org/licenses/by/4.0/

Piper runtime: https://github.com/OHF-Voice/piper1-gpl (GPL-3.0, generation tool only).
Piper is used only to generate Test 05 locally. The website does not run or
download Piper. WAV segments are concatenated with 0.4-second gaps and encoded
as 64-kbps MP3. These modifications produce practice audio, not copies of VCTK
recordings. No speaker or institution is represented as endorsing the website.

## Tests 05 and 06 — current Kokoro audio

American male voice: `am_michael`. British female voice: `bf_emma`. Both are
Kokoro-82M voices; speech is generated at speed 1.1. Test 05 and 06 scripts were sent
to the public Hugging Face Space for synthesis. Only the resulting 24-kHz mono,
64-kbps MP3 files are included in this website; its pages do not call the Space
at playback time. Speaker turns are separated by 0.4 seconds.

- Model: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0 weights)
- Voice definitions: https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md
- Public synthesis Space: https://huggingface.co/spaces/hexgrad/Kokoro-TTS

No voice or institution is represented as endorsing the website.
