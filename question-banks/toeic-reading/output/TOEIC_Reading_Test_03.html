PART 5 — Incomplete Sentences（101–130）

Directions: A word or phrase is missing in each of the sentences below. Four answer choices are given below each sentence. Select the best answer to complete the sentence. Then mark the letter (A), (B), (C), or (D) on your answer sheet.
101.The manager reviewed the proposal carefully ____ approving the additional funding.
  1. Awhile
  2. Bbefore
  3. Cduring
  4. Dsince
解析 / Explanation
B. 'Before' + gerund shows the review happens prior to the approval.
102.The customer service team responded ____ to every complaint it received.
  1. Aprompt
  2. Bpromptly
  3. Cpromptness
  4. Dprompted
解析 / Explanation
B. An adverb is needed to modify the verb 'responded', so 'promptly' is correct.
103.Mr. Ito, ____ team won the innovation award, will lead the new division.
  1. Awho
  2. Bwhom
  3. Cwhose
  4. Dwhich
解析 / Explanation
C. The possessive relative pronoun 'whose' is needed before the noun 'team'.
104.Sales in the online store have risen ____ since the website was redesigned.
  1. Asharp
  2. Bsharper
  3. Csharply
  4. Dsharpness
解析 / Explanation
C. An adverb is needed to modify 'have risen', so 'sharply' is correct.
105.Neither the director nor the board members ____ aware of the delay until yesterday.
  1. Ais
  2. Bwas
  3. Care
  4. Dhas
解析 / Explanation
C. With 'neither...nor', the verb agrees with the nearer subject 'board members', which is plural, so 'are'.
106.The new privacy policy will ____ all employees, so please read it carefully.
  1. Aaffect
  2. Beffect
  3. Ceffective
  4. Daffection
解析 / Explanation
A. The verb 'affect' means 'to influence'; 'effect' as a noun and the others do not fit here.
107.The store will reopen ____ Monday, once the holiday weekend is over.
  1. Ain
  2. Bby
  3. Cat
  4. Don
解析 / Explanation
D. The preposition 'on' is used with a day, so 'on Monday'.
108.By the time the manager called, the team ____ the presentation.
  1. Afinished
  2. Bhave finished
  3. Chad finished
  4. Dfinish
解析 / Explanation
C. The past perfect 'had finished' shows the action was completed before another past event.
109.Applications must be received ____ the end of the month to be considered.
  1. Afor
  2. Buntil
  3. Csince
  4. Dby
解析 / Explanation
D. 'By' marks the deadline meaning 'no later than'.
110.The guest lecture was so ____ that no one wanted it to end.
  1. Ainterest
  2. Binterested
  3. Cinteresting
  4. Dinterestingly
解析 / Explanation
C. The '-ing' adjective 'interesting' describes something that causes interest, which fits the lecture.
111.Each of the regional offices ____ submitted its annual report on time.
  1. Ahave
  2. Bhas
  3. Cwere
  4. Dare
解析 / Explanation
B. The subject 'Each' is singular, so the singular verb 'has' is correct.
112.The firm hired an experienced ____ to oversee the construction project.
  1. Amanage
  2. Bmanaged
  3. Cmanaging
  4. Dmanager
解析 / Explanation
D. A noun naming a person is needed after 'an experienced', so 'manager' is correct.
113.The outdoor concert was cancelled ____ a severe storm over the region.
  1. Abecause of
  2. Balthough
  3. Cdespite
  4. Deven though
解析 / Explanation
A. 'Because of' introduces a noun phrase giving the reason for the cancellation.
114.Employees who complete the survey ____ entered into a prize draw.
  1. Ais
  2. Bare
  3. Cwas
  4. Dbeing
解析 / Explanation
B. The plural subject 'Employees' takes the plural passive verb 'are entered'.
115.The second design was received far more ____ than the first by the review panel.
  1. Afavorable
  2. Bfavorably
  3. Cfavorabler
  4. Dfavor
解析 / Explanation
B. With 'more...than', the base adverb 'favorably' is required to modify 'was received'.
116.The documents ____ during the meeting will be circulated to all staff tomorrow.
  1. Adiscuss
  2. Bdiscusses
  3. Cdiscussed
  4. Ddiscussing
解析 / Explanation
C. The reduced passive clause 'the documents (that were) discussed' requires the past participle 'discussed'.
117.Please ensure the machine is ____ shut down at the end of each working day.
  1. Acomplete
  2. Bcompletely
  3. Ccompletion
  4. Dcompleted
解析 / Explanation
B. An adverb is needed to modify 'shut down', so 'completely' is correct.
118.The launch date depends ____ the results of the final round of tests.
  1. Aon
  2. Bof
  3. Cat
  4. Dto
解析 / Explanation
A. The verb 'depend' is followed by the preposition 'on'.
119.____ the report was thorough, it arrived a full week after the deadline.
  1. ASo
  2. BBecause
  3. CSince
  4. DAlthough
解析 / Explanation
D. The contrast between a thorough report and its lateness calls for the concession word 'Although'.
120.This supplier's service is far more dependable than ____ we used before.
  1. Aone
  2. Bthe one
  3. Cthat ones
  4. Dthose one
解析 / Explanation
B. 'The one' refers back to a single supplier, matching 'this supplier'.
121.All staff must ____ with the updated fire-safety rules without exception.
  1. Acomply
  2. Badhere
  3. Cobserve
  4. Dfollow
解析 / Explanation
A. 'Comply' pairs with 'with'; 'adhere' would take 'to', and the others take a direct object.
122.The booth will be ____ by the marketing team before the trade show opens.
  1. Aset
  2. Bsetting
  3. Cto set
  4. Dset up
解析 / Explanation
D. The phrasal verb 'set up' completes the passive structure 'will be set up'.
123.Our flagship store earns more revenue than ____ branch in the country.
  1. Aany other
  2. Bother any
  3. Cthe other any
  4. Dany others
解析 / Explanation
A. 'Any other' correctly compares the flagship store against every remaining branch.
124.There has been a noticeable ____ in customer inquiries since the campaign began.
  1. Arises
  2. Brisen
  3. Crising
  4. Drise
解析 / Explanation
D. A singular noun is needed after 'a noticeable', so 'rise' is correct.
125.The new app allows users ____ their orders in real time from any device.
  1. Atrack
  2. Btracking
  3. Cto track
  4. Dtracked
解析 / Explanation
C. The pattern 'allow + object + to-infinitive' requires 'to track'.
126.No one may access the server room ____ proper authorization from IT.
  1. Awithout
  2. Bunless
  3. Cdespite
  4. Dexcept
解析 / Explanation
A. 'Without' + noun means lacking authorization; 'unless' would need a clause.
127.The two teams collaborated ____ to finish the project ahead of schedule.
  1. Aclose
  2. Bclosely
  3. Ccloser
  4. Dclosest
解析 / Explanation
B. An adverb is needed to modify 'collaborated', so 'closely' is correct.
128.____ receiving your confirmation, we will ship your order the same day.
  1. ASince
  2. BDuring
  3. CWhile
  4. DUpon
解析 / Explanation
D. 'Upon receiving' means immediately after receiving, which fits the promise.
129.Of all the proposals submitted, hers was the ____ practical and well researched.
  1. Amuch
  2. Bmore
  3. Cmost
  4. Dmany
解析 / Explanation
C. Comparing one proposal against the whole group requires the superlative, so 'the most'.
130.We will contact you ____ a decision has been made about your application.
  1. Aas soon as
  2. Bin order to
  3. Cso that
  4. Din case
解析 / Explanation
A. 'As soon as' introduces the time at which the contact will happen.
