# TOEIC® Reading 练习 · 10 套（含答案与解析）

> 当前发布入口已迁移到 TypeScript。请编辑本目录的 `pages.json`（题目、选项、答案、解析、页面文本）和 `bank.mts`（题库声明）；在仓库根目录运行 `node scripts/build-banks.mjs --bank toeic-reading`。页面布局在 `quiz_kit/typescript/layouts.mts`。下方旧 Python/HTML 流程仅供历史采集参考；详见[统一维护说明](../README.md)。

| 部分 | 题型 | 题量 | 题号 |
|---|---|---|---|

## 怎么用（可作答版）

打开 **`index.html`** → 选一套 → **点选项 →「确认作答」**，立刻判对错并展开解析。

| 功能 | 说明 |
|---|---|
| **判对错** | 答对绿色 ✓，答错红色 ✗ 并把正确项标为黄色「正解」 |
| **正确率统计** | 顶部实时显示「已答 / 正确 / 错误 / 正确率」+ 进度条 |
| **答题卡** | 一键弹出 100 格总览，颜色区分对错，点格跳转 |
| **交卷** | 显示最终正确率、答题数、用时 |
| **只看错题** | 一键过滤，反复刷错题 |
| **进度保存** | 存在本机浏览器，关掉再开继续做（换设备不同步） |
| **重做本题** / **直接看答案** | 单题重做；直接看答案不计入正确率 |
| **打印 / 存 PDF** | 输出纯题面，解析自动另起一页 |

> 手机浏览器打开同样可用，Safari「添加到主屏幕」后跟 App 一样。
> 进度只存在当前设备的浏览器里，清除 Safari 数据会一并清空。

需要源文本编辑的，用同名的 `.md` 文件。
