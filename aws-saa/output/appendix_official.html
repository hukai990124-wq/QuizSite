Question 1

A company runs a public-facing three-tier web application in a VPC across multiple Availability Zones. Amazon EC2 instances for the application tier running in private subnets need to download software patches from the internet. However, the EC2 instances cannot be directly accessible from the internet. Which actions should be taken to allow the EC2 instances to download the needed patches? (Select TWO.)

一家公司在跨多个可用区的 VPC 中运行面向公众的三层 Web 应用程序。在私有子网中运行的应用层的 Amazon EC2 实例需要从互联网下载软件补丁。但是，无法从 Internet 直接访问 EC2 实例。应采取哪些操作来允许 EC2 实例下载所需的补丁？ （选择两项。）

  1. A

    Configure a NAT gateway in a public subnet.

    在公有子网中配置 NAT 网关。

  2. B

    Define a custom route table with a route to the NAT gateway for internet traffic and associate it with the private subnets for the application tier.

    定义一个自定义路由表，其中包含到 Internet 流量的 NAT 网关的路由，并将其与应用程序层的私有子网关联。

  3. C

    Assign Elastic IP addresses to the EC2 instances.

    为 EC2 实例分配弹性 IP 地址。

  4. D

    Define a custom route table with a route to the internet gateway for internet traffic and associate it with the private subnets for the application tier.

    定义一个自定义路由表，其中包含到 Internet 流量的 Internet 网关的路由，并将其与应用程序层的私有子网关联。

  5. E

    Configure a NAT instance in a private subnet.

    在私有子网中配置 NAT 实例。

多选 · 需选 2 项
解析 / Explanation

正确答案 A, B

A NAT gateway forwards traffic from the EC2 instances in the private subnet to the internet or other AWS services, and then sends the response back to the instances. After a NAT gateway is created, the route tables for private subnets must be updated to point internet traffic to the NAT gateway.

NAT 网关将流量从私有子网中的 EC2 实例转发到互联网或其他 AWS 服务，然后将响应发送回实例。创建 NAT 网关后，必须更新私有子网的路由表，以将 Internet 流量指向 NAT 网关。

Question 2

A solutions architect wants to design a solution to save costs for Amazon EC2 instances that do not need to run during a 2-week company shutdown. The applications running on the EC2 instances store data in instance memory that must be present when the instances resume operation. Which approach should the solutions architect recommend to shut down and resume the EC2 instances?

解决方案架构师想要设计一个解决方案，以节省在公司停工 2 周期间不需要运行的 Amazon EC2 实例的成本。 EC2 实例上运行的应用程序将数据存储在实例内存中，当实例恢复运行时这些数据必须存在。解决方案架构师应建议采用哪种方法来关闭和恢复 EC2 实例？

  1. A

    Modify the application to store the data on instance store volumes. Reattach the volumes while restarting them.

    修改应用程序以将数据存储在实例存储卷上。重新启动卷时重新附加它们。

  2. B

    Snapshot the EC2 instances before stopping them. Restore the snapshot after restarting the instances.

    在停止 EC2 实例之前对其进行快照。重启实例后恢复快照。

  3. C

    Run the applications on EC2 instances enabled for hibernation. Hibernate the instances before the 2- week company shutdown.

    在启用休眠功能的 EC2 实例上运行应用程序。在公司关闭两周之前使实例休眠。

  4. D

    Note the Availability Zone for each EC2 instance before stopping it. Restart the instances in the same Availability Zones after the 2-week company shutdown.

    在停止之前记下每个 EC2 实例的可用区。公司关闭两周后，重新启动同一可用区中的实例。

解析 / Explanation

正确答案 C

Hibernating EC2 instances save the contents of instance memory to an Amazon Elastic Block Store (Amazon EBS) root volume. When the instances restart, the instance memory contents are reloaded.

休眠 EC2 实例将实例内存的内容保存到 Amazon Elastic Block Store (Amazon EBS) 根卷。当实例重新启动时，实例内存内容将重新加载。

Question 4

An analytics company is planning to offer a web analytics service to its users. The service will require that the users’ webpages include a JavaScript script that makes authenticated GET requests to the company’s Amazon S3 bucket. 一家分析公司正计划为其用户提供网络分析服务。该服务将要求用户的网页包含一个 JavaScript 脚本，该脚本向公司的 Amazon S3 存储桶发出经过身份验证的 GET 请求。解决方案架构师必须做什么才能确保脚本成功执行？

    Enable cross-origin resource sharing (CORS) on the S3 bucket.

    Enable S3 Versioning on the S3 bucket.

    在 S3 存储桶上启用 S3 版本控制。

  3. C

    Provide the users with a signed URL for the script.

    向用户提供脚本的签名 URL。

Web browsers will block running a script that originates from a server with a domain name that is different from the webpage. Amazon S3 can be configured with CORS to send HTTP headers that allow the script to run.

Web 浏览器将阻止运行源自域名与网页不同的服务器的脚本。 Amazon S3 可以配置 CORS 以发送允许脚本运行的 HTTP 标头。

Question 5

A company’s security team requires that all data stored in the cloud be encrypted at rest at all times using encryption keys stored on premises. Which encryption options meet these requirements? (Select TWO.)

公司的安全团队要求使用本地存储的加密密钥始终对存储在云中的所有数据进行静态加密。哪些加密选项满足这些要求？ （选择两项。）

  1. A

    Use server-side encryption with Amazon S3 managed encryption keys (SSE-S3).

    使用带有 Amazon S3 托管加密密钥 (SSE-S3) 的服务器端加密。

  2. B

    Use server-side encryption with AWS KMS managed encryption keys (SSE-KMS).

    使用带有 AWS KMS 托管加密密钥 (SSE-KMS) 的服务器端加密。

  3. C

    Use server-side encryption with customer-provided encryption keys (SSE-C).

    使用带有客户提供的加密密钥的服务器端加密 (SSE-C)。

  4. D

    Use client-side encryption to provide at-rest encryption.

    使用客户端加密来提供静态加密。

  5. E

    Use an AWS Lambda function invoked by Amazon S3 events to encrypt the data using the customer’s keys.

    使用 Amazon S3 事件调用的 AWS Lambda 函数来使用客户密钥加密数据。

多选 · 需选 2 项
解析 / Explanation

正确答案 C, D

Server-side encryption with customer-provided keys (SSE-C) enables Amazon S3 to encrypt objects on the server side using an encryption key provided in the PUT request. The same key must be provided in the GET requests for Amazon S3 to decrypt the object. Customers also have the option to encrypt data on the client side before uploading it to Amazon S3, and then they can decrypt the data after downloading it. AWS software development kits (SDKs) provide an S3 encryption client that streamlines the process.

使用客户提供的密钥进行服务器端加密 (SSE-C) 使 Amazon S3 能够使用 PUT 请求中提供的加密密钥来加密服务器端的对象。必须在 Amazon S3 的 GET 请求中提供相同的密钥才能解密对象。客户还可以选择在将数据上传到 Amazon S3 之前在客户端加密数据，然后在下载数据后解密数据。 AWS 软件开发工具包 (SDK) 提供了可简化流程的 S3 加密客户端。

Question 7

A company runs an online voting system for a weekly live television program. During broadcasts, users submit hundreds of thousands of votes within minutes to a front-end fleet of Amazon EC2 instances that run in an Auto Scaling group. The EC2 instances write the votes to an Amazon RDS database. However, the database is unable to keep up with the requests that come from the EC2 instances. A solutions architect must design a solution that processes the votes in the most efficient manner and without downtime. Which solution meets these requirements?

一家公司为每周的直播电视节目运行在线投票系统。在广播期间，用户在几分钟内向 Auto Scaling 组中运行的 Amazon EC2 实例前端队列提交数十万张选票。 EC2 实例将投票写入 Amazon RDS 数据库。但是，数据库无法跟上来自 EC2 实例的请求。解决方案架构师必须设计一个能够以最有效的方式处理投票且无需停机的解决方案。哪种解决方案满足这些要求？

    Migrate the front-end application to AWS Lambda. Use Amazon API Gateway to route user requests to the Lambda functions.

    将前端应用程序迁移到 AWS Lambda。使用 Amazon API Gateway 将用户请求路由到 Lambda 函数。

  2. B

    Scale the database horizontally by converting it to a Multi-AZ deployment. Configure the front-end application to write to both the primary and secondary DB instances.

    通过将数据库转换为多可用区部署来水平扩展数据库。配置前端应用程序以写入主数据库实例和辅助数据库实例。

  3. C

    Configure the front-end application to send votes to an Amazon Simple Queue Service (Amazon SQS) queue. Provision worker instances to read the SQS queue and write the vote information to the database.

    配置前端应用程序以将投票发送到 Amazon Simple Queue Service (Amazon SQS) 队列。配置工作实例以读取 SQS 队列并将投票信息写入数据库。

正确答案 C

Decouple the ingestion of votes from the database to allow the voting system to continue processing votes without waiting for the database writes. Add dedicated workers to read from the SQS queue to allow votes to be entered into the database at a controllable rate. The votes will be added to the database as fast as the database can process them, but no votes will be lost.

将投票的摄取与数据库解耦，以允许投票系统继续处理投票，而无需等待数据库写入。添加专门的工作人员从 SQS 队列中读取数据，以允许以可控的速率将选票输入数据库。选票将按照数据库处理它们的速度添加到数据库中，但不会丢失任何选票。

Question 9

A website runs a custom web application that receives a burst of traffic each day at noon. The users upload new pictures and content daily, but have been complaining of timeouts. The architecture uses Amazon EC2 Auto Scaling groups, and the application consistently takes 1 minute to initiate upon boot up before responding to user requests. How should a solutions architect redesign the architecture to better respond to changing traffic?

某个网站运行一个自定义 Web 应用程序，该应用程序每天中午都会收到大量流量。用户每天都会上传新的图片和内容，但一直抱怨超时。该架构使用 Amazon EC2 Auto Scaling 组，并且应用程序在启动时始终需要 1 分钟才能响应用户请求。解决方案架构师应该如何重新设计架构以更好地响应不断变化的流量？

  1. A

    Configure a Network Load Balancer with a slow start configuration.

    使用慢启动配置配置 Network Load Balancer。

  2. B

    Configure Amazon ElastiCache for Redis to offload direct requests from the EC2 instances.

    为 Redis 配置 Amazon ElastiCache 以卸载来自 EC2 实例的直接请求。

  3. C

    Configure an Auto Scaling step scaling policy with an EC2 instance warmup condition.

    配置具有 EC2 实例预热条件的 Auto Scaling 步骤扩展策略。

  4. D

    Configure Amazon CloudFront to use an Application Load Balancer as the origin.

    配置 Amazon CloudFront 以使用 Application Load Balancer 作为源。

解析 / Explanation

正确答案 C

The current configuration puts new EC2 instances into service before they are able to respond to transactions. This could also cause the instances to overscale. With a step scaling policy, you can specify the number of seconds that it takes for a newly launched instance to warm up. Until its specified warm-up time has expired, an EC2 instance is not counted toward the aggregated metrics of the Auto Scaling group. While scaling out, the Auto Scaling logic does not consider EC2 instances that are warming up as part of the current capacity of the Auto Scaling group. Therefore, multiple alarm breaches that fall in the range of the same step adjustment result in a single scaling activity. This ensures that you do not add more instances than you need.

当前配置将新的 EC2 实例投入使用，然后才能响应事务。这也可能导致实例规模过大。通过逐步扩展策略，您可以指定新启动的实例预热所需的秒数。在指定的预热时间到期之前，EC2 实例不会计入 Auto Scaling 组的聚合指标中。横向扩展时，Auto Scaling 逻辑不会将正在预热的 EC2 实例视为 Auto Scaling 组当前容量的一部分。因此，同一步长调整范围内的多个警报违规会导致一次伸缩活动。这可确保您添加的实例不会超出您的需要。
