# DELE A1 · 阅读 + 写作 + 听力 练习册

把 Instituto Cervantes 官方公开的 **5 套 A1 试卷**做成可作答、可判分的单文件 HTML。
沿用 `../quiz_kit/quizkit.py` 判分引擎（与 TOEIC / AWS 题库同一套交互）。

- **Prueba 1 阅读**：25 题，即时判分
- **Prueba 2 听力**：25 题（4 套有；3 套带音频，可展开官方原文对照）
- **Prueba 3 写作**：2 题，不判分，附参考答案
- Prueba 4 口语：考试有，但无法在网页里练，未收录

听力与阅读**共用一张答题卡**：页面把听力接续编号为 **第 26–50 题**
（真题里 Prueba 2 独立编号 1–25）。每个 Tarea 上方另有一行小字标出「原卷 Prueba 2 · 第 N – M 题」，
方便对着官方原卷核对。

## 打开方式

直接双击 `out/index.html`（纯静态，无需服务器；图片是相对路径 `out/img/`、音频是 `out/audio/`）。
进度存在浏览器 localStorage（key = `quiz:dele-a1-<slug>`），换设备不共享。

## 界面：电脑 / 手机两套 UI（同一份文件）

不用做两份 HTML —— 靠 CSS 媒体查询按屏幕宽度自动切换，浏览器自己判断：

| | **电脑（≥1080px）** | **手机（≤640px）** |
|---|---|---|
| 版式 | 左侧 300px 常驻侧栏 + 右侧题目（双栏） | 单列全宽 |
| 操作区 | 侧栏竖排按钮 + 统计 + 进度条 | 顶部 sticky 一行，可横向滑动 |
| 触摸目标 | 常规 | 按钮 **≥44px**（iOS 建议值） |
| 宽表格 | 完整显示 | 横向滑动 + 「← 左右滑动查看 →」提示 |
| 答题卡 | 右下角浮动面板 | 底部通栏浮层 |
| 首页卡片 | 5 列 | 单列 |

断点：`≤640` 手机 · `641–1079` 平板/小笔记本（单栏居中）· `≥1080` 桌面双栏。

实现要点在 `build.py` 的 `RESP_CSS`：**响应式样式必须拼在引擎 CSS 之后**
（引擎 `quizkit.py` 里 `.qbar` / `.sheet` 等同名规则、以及 `max-width:560px` 下的
`!important` 收缩规则会覆盖先加载的 `BASE_CSS`，只有放到最后才压得住）。

## 听力音频是怎么来的

| 套卷 | 来源 | 说明 |
|---|---|---|
| 2020 样卷 | **官方公开音频包** | 真人录音，直接用官方 mp3，未做任何处理 |
| 2008 样卷 / 2011 真题 | **神经语音合成** | 官方从未发布音频，按官方 `transcripción`（听力原文）逐段合成 |
| 2009 真题 | **无音频** | 官方既没发录音也没发原文，页面只能看题型与答案 |

- 合成用 `edge-tts` 的西班牙语神经语音：`es-ES-AlvaroNeural`（男）、`es-ES-ElviraNeural`（女）、
  `es-ES-XimenaNeural`（旁白），语速 `-10%`（更接近考试朗读速度）。
- **真题节奏必须复现**，否则听力填空（Tarea 4）根本没法做：官方流程是「同一段读 N 遍 + 留作答停顿」。
  `build_audio.py` 的 `REPEAT` 表就是这件事：
  **Tarea 1/2/3 = 读 2 遍各留 6 秒；Tarea 4 = 读 3 遍各留 30 秒**。
- 静音段用 ffmpeg `lavfi anullsrc` 生成；拼接**不能**用 `-c copy`
  （静音段与语音段 mp3 帧参数不一致会报 dts 非单调，得统一重编码成 `-ac 1 -ar 24000 -b:a 48k`）。
- 音频是**懒加载**（`<audio controls preload="none">`）：不点播放键就不下载，整站音频 18.9 MB 不会一次性吃掉流量。

## 图片选项

听力 Tarea 1 和阅读第 5 题都是「看图选答案」。图片用 PyMuPDF 的
`get_image_info()` 取 bbox → 按 y 聚类成行、行内按 x 排序（顺序天然就是 A/B/C/D）→
`get_pixmap(clip=…)` 裁出来。

- 2008 那套每页有 2500+ 装饰碎片，必须靠 `MIN_W/MIN_H = 40` 过滤。
- 300dpi 原图是 PNG（126 张 ≈ 11 MB）→ 统一转 **JPEG q=85 且长边 ≤420px**，
  压到 **2.2 MB**（省 9 MB），肉眼几乎无差别。

### ⚠️ 上线前一定要跑 `sync_site.py`

`site/dele-a1/` 不是 `out/` 的简单拷贝，站点侧比 `out/` 多三样东西：

1. `index.html` 右上角固定的「← 题库总览」链接（回到站点首页）
2. **三语切换**（`quiz_kit/i18n_inject.py` 注入，幂等）
3. 左下角**在线人数**控件 `<!--pc:js-->` 引用 `assets/presence.js`

直接 `cp -r out/ site/dele-a1/` 会把这个三样冲掉。`sync_site.py` 把整条链路固化成一个命令。

## 三语（中 / EN / 日）

- 词典在 `../quiz_kit/i18n.json`，运行时在 `../quiz_kit/i18n_runtime.js`。
- **只翻界面文案，题目 / 选项 / 解析 / 原文一律不翻**。保障来自两道锁：
  ① 区域规则（WHITE / BLACK 名单）② 字典是精确匹配（规范化后全等），不是模糊替换。
- 听力播放器的 `.aud` 特意加进了 WHITE 白名单 —— 它常被放在题目区（BLACK）里面，
  但里面只有「示例录音 / 第 N 题录音」这类播放器标签，没有题目内容。
- 覆盖度自检：`../quiz_kit/i18n_scan.py`（用真实浏览器 + **未翻译的原始 DOM** 复刻运行时判定，
  列出所有「会被翻但词典里没有」的串）。当前全站 70 页 **0 缺口**。

## 解析过程中的已知坑

1. **2020-07 真题的文本层是自定义字体编码**，`get_text()` 出来是乱码 → 逐页渲染 PNG 后视觉重建。
2. **多列/分栏排版 OCR 会串行** —— 匹配题的 A–J 卡片必须靠读图确认字母位置，不能信 OCR 顺序。
3. **2009 原卷印刷笔误**：行程表第 2、3 栏都印成 `MIÉRCOLES`。官方答案把「去购物」那天记为 `MARTES`，
   所以第 20 题两种写法都算对，页面里也加了提示框。
4. **图片选项**用 PyMuPDF `get_image_info()` 取 bbox 后裁图，不是截图；
   2009 那题的 4 张裁图顺序与 PDF 视觉顺序不一致，已重命名修正。
5. **听力原文里的括号舞台指示**（如 `(10 segundos)`、`(Repite)`）要剥掉，
   否则会当成朗读内容念出来 —— 见 `parse_trans.py` 的 `_clean_trans_line()`。
