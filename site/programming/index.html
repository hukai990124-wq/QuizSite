Question 1单选HTML · Code review

Review this image markup. Which replacement correctly uses the HTML image element and a text alternative?

审查这段图片代码：哪项正确使用 HTML 图片标签，并提供替代文字？

画像のコードをレビューする。HTMLの画像要素と代替テキストを正しく使う修正はどれか。

<image href="cat.jpg" title="Cat"></image>
  1. A
  2. B
  3. C
  4. D
解析 / Explanation

正确答案 A

Use img with src for the image URL and alt for its text alternative. title supplies advisory information, not a replacement for alt. img is a void element and has no closing tag.

图片用 img，地址用 src，替代文字用 alt。title 是补充提示，不能代替 alt。img 是空元素，不写结束标签。

画像はimg、画像URLはsrc、代替テキストはaltを使う。titleは補足情報で、altの代用ではない。imgは空要素なので終了タグを書かない。

The paragraph needs a proper closing tag. Which repair is correct?

段落缺少正确的结束标签，哪项修复正确？

段落の終了タグを正しく直すのはどれか。

  1. A
  2. B
  3. C
  4. D
解析 / Explanation

正确答案 C

An end tag places / before the tag name: </p>. <p/> does not close a paragraph in HTML. A bare </> is not an HTML end tag either.

结束标签的斜杠放在标签名前： </p>。HTML 中 <p/> 不会关闭段落，单独的 </> 也不是有效的 HTML 结束标签。

終了タグは名前の前に/を置く： </p>。HTMLでは<p/>で段落は閉じられず、</>もHTMLの終了タグではない。

head内のtitle要素がタブに表示する文書タイトルを定義する。h1はbody内の見出し。title属性とtitle要素は別物だ。

Question 6单选HTML · Code review

空白を含む属性値は引用符で囲む。引用符がないとtitleの値はRedまでで、catは別の属性として解析される。ツールチップはaltの代わりにはならない。

Question 7单选HTML · Code review

Which repair uses the HTML line-break element without an invalid closing tag?

哪项正确使用 HTML 换行元素，且没有无效的结束标签？

  4. D
解析 / Explanation

br 是空元素，写 <br>，不写 </br>。HTML 中也允许 <br />，但尾部斜杠并没有自闭合效果。break 不是 HTML 换行元素。

brは空要素なので<br>と書き、</br>は付けない。HTMLでは<br />も許容されるが、末尾の/に自己終了の効果はない。breakは改行要素ではない。

type=buttonなら送信もリセットも行わない通常のボタンになる。submitは送信、resetは入力のリセットで、previewは有効なtypeではない。フォーム内ではtypeを明示する。

Question 12单选HTML · Code review

Two different elements reuse an id. Which version gives both unique identifiers?

两个不同元素重复使用 id，哪项修复后两者都有唯一标识？

2つの要素でidが重複している。それぞれを一意に識別できる修正はどれか。

<h1 id="intro">Intro</h1>
<p id="intro">Details</p>
  1. A
  2. B
  3. C
  4. D
解析 / Explanation

正确答案 B

An id must be unique within its document tree. Different IDs distinguish the heading and paragraph. Adding a class does not fix a duplicated id; classes, unlike IDs, may be shared.

同一文档树内 id 必须唯一。使用不同 id 才能区分标题和段落。增加 class 不会消除 id 重复；class 则可以在多个元素间共享。

同じ文書ツリー内のidは一意にする。見出しと段落に別のidを付ける。classを追加してもidの重複は解消しない。classは複数要素で共有できる。

Replace this JavaScript-style note with a real HTML comment. Which syntax is correct?

JavaScript風のメモをHTMLのコメントに直す。正しい構文はどれか。

  2. B
  3. C
  4. D
解析 / Explanation

正确答案 C

HTML 注释用 <!-- 与 -->。// 是 JavaScript 风格，/* */ 用于 CSS、JavaScript，不是普通 HTML 注释。注释仍能在源码中查看，不可放密钥。

HTMLのコメントは<!--と-->で囲む。//や/* */は通常のHTMLコメントにならない。コメントはソースから読めるので秘密情報を置かない。

Question 15单选HTML · Code review

Which replacement creates a complete minimal HTML document with the title in head and content in body?

titleをheadに、本文をbodyに置いた最小限の完全なHTML文書はどれか。

  1. A
  2. B
  3. C
  4. D

正确答案 D

doctype 让浏览器使用标准模式。head 放 title 等元数据，body 放可见段落。浏览器会修复许多错误，但审查源码仍应检查正确的结构和边界。

doctypeで標準モードを選ぶ。headにはtitleなどのメタデータ、bodyには表示する段落を置く。ブラウザーの補正に頼らず構造とタグの境界を確認する。

table、tr（行）、td（データセル）の順に入れる。ブラウザーがtbodyを自動挿入する場合もあるが正常な動作だ。rowは標準の行要素ではない。
