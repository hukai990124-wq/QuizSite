怎么用
  • 进任意一份 → 点选项 →「确认作答」→ 立刻判对错、显示正确答案与解析。
  • 多选题会提示「需选 N 项」；选错也不会卡住，随时可提交。
  • 顶部实时显示 已答 / 正确 / 错误 / 正确率；右上「交卷」看总成绩与用时。
  • 进度存在本机浏览器，关掉再打开继续做。「只看错题」可反复刷错题。
  • 「打印 / 存 PDF」会输出纯净题面（答案与解析另起一页）。
  • 每份另有 .md 文件，可直接编辑或导入 Anki。
两点必读
  • 中文为机器翻译（Google 引擎 + 术语白名单），用于辅助理解；术语与表述以英文原文为准。
  • A 线属「考生回忆真题」，AWS 认证协议禁止传播考试内容——请勿再分发或商用。B 线与官方样题可正常使用。
