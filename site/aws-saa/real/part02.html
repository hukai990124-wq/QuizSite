Question 51Single answer

A company is running a web application on Amazon EC2 instances behind an Application Load Balancer (ALB). The application is accessible over HTTPS, and the company wants to ensure that only HTTPS traffic is allowed to reach the instances. How can the company achieve this?

一家公司正在 Application Load Balancer (ALB) 后面的 Amazon EC2 实例上运行 Web 应用程序。该应用程序可通过 HTTPS 访问，并且该公司希望确保仅允许 HTTPS 流量到达实例。公司如何才能实现这一目标？

  1. A

    Configure the ALB to redirect all HTTP traffic to HTTPS.

    配置 ALB 以将所有 HTTP 流量重定向到 HTTPS。

  2. B

    Modify the ALB's security group to allow only inbound traffic on port 443.

    修改 ALB 的安全组以仅允许端口 443 上的入站流量。

  3. C

    Set up a Network ACL to block all traffic except for HTTPS on port 443.

    设置网络 ACL 以阻止端口 443 上除 HTTPS 之外的所有流量。

  4. D

    Add a rule to the EC2 instance security group to allow HTTPS traffic and block all other traffic.

    向 EC2 实例安全组添加规则以允许 HTTPS 流量并阻止所有其他流量。

解析 / Explanation

正确答案 B

To ensure that only HTTPS traffic reaches the EC2 instances, the correct approach is to modify the Application Load Balancer's security group to allow inbound traffic only on port 443, which is used for HTTPS. This ensures that any non-HTTPS traffic is blocked before it reaches the ALB, aligning with the company's requirement for secure communication.

为了确保只有 HTTPS 流量到达 EC2 实例，正确的方法是修改 Application Load Balancer 的安全组，以仅允许用于 HTTPS 的端口 443 上的入站流量。这可确保任何非 HTTPS 流量在到达 ALB 之前被阻止，从而符合公司对安全通信的要求。
