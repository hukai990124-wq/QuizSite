您的公司正在 AWS 上部署机器学习模型来对敏感客户数据进行分类。为了满足合规性和安全性要求，您应该实施哪种方法组合来保护人工智能系统？

  1. A

    Encrypt data at rest using AWS Key Management Service (KMS).

    使用 AWS Key Management Service (KMS) 加密静态数据。

  2. B

    Use AWS Identity and Access Management (IAM) roles to restrict access to the model and data.

    使用 AWS Identity and Access Management (IAM) 角色来限制对模型和数据的访问。

  3. C

    Host the model on an Amazon EC2 instance without enabling security groups to avoid unnecessary overhead.

    在 Amazon EC2 实例上托管模型，无需启用安全组，以避免不必要的开销。

  4. D

    Implement Amazon SageMaker endpoint encryption for data in transit.

    对传输中的数据实施 Amazon SageMaker 端点加密。

  5. E

    Expose the model endpoint publicly to simplify accessibility for all users.

    公开公开模型端点以简化所有用户的可访问性。

多选 · 需选 3 项
解析 / Explanation

正确答案 A,B,D

To secure an AI system on AWS, it is crucial to follow best practices such as encrypting data at rest and in transit, restricting access through IAM roles, and ensuring endpoints are not publicly exposed. These measures collectively protect sensitive data and the overall integrity of the system.
A. Correct. Encrypting data at rest using AWS KMS ensures that sensitive customer data stored in services like S3, SageMaker, or RDS remains secure and compliant with data protection regulations.
B. Correct. Using AWS IAM roles to restrict access prevents unauthorized users from accessing the model, training data, or sensitive customer information, thereby enhancing security.
C. Incorrect. Hosting the model on an EC2 instance without enabling security groups would leave it exposed to potential attacks, which violates best practices for securing AWS resources.
D. Correct. Amazon SageMaker endpoint encryption ensures that data transmitted to and from the model endpoint is encrypted, protecting it from interception during transit.
E. Incorrect. Exposing the model endpoint publicly would make it vulnerable to unauthorized access and attacks, undermining the security of the AI system.

为了保护 AWS 上的 AI 系统，遵循最佳实践至关重要，例如对静态和传输中的数据进行加密、通过 IAM 角色限制访问以及确保端点不公开暴露。这些措施共同保护敏感数据和系统的整体完整性。答：正确。使用 AWS KMS 加密静态数据可确保存储在 S3、SageMaker 或 RDS 等服务中的敏感客户数据保持安全并符合数据保护法规。 B、正确。使用 AWS IAM 角色来限制访问，防止未经授权的用户访问模型、训练数据或敏感客户信息，从而增强安全性。 C、不正确。在不启用安全组的情况下在 EC2 实例上托管模型会使其面临潜在的攻击，这违反了保护 AWS 资源的最佳实践。 D、正确。Amazon SageMaker 端点加密可确保对模型端点传输的数据进行加密，从而防止数据在传输过程中被拦截。 E、不正确。公开暴露模型端点将使其容易受到未经授权的访问和攻击，从而破坏人工智能系统的安全性。

  1. A

    Encrypt data at rest and in transit using AWS Key Management Service (KMS).

    使用 AWS Key Management Service (KMS) 加密静态和传输中的数据。

  2. B

    Use AWS Identity and Access Management (IAM) to restrict access to the AI system and associated resources.

    使用 AWS Identity and Access Management (IAM) 限制对 AI 系统和相关资源的访问。

  3. C

    Disable logging to avoid exposing sensitive data in logs.

    禁用日志记录以避免暴露日志中的敏感数据。

  4. D

    Implement endpoint protection by using Amazon SageMaker endpoint encryption.

    使用 Amazon SageMaker 端点加密实现端点保护。

  5. E

    Enable multi-factor authentication (MFA) for all AWS accounts accessing the system.

    为访问系统的所有 AWS 账户启用多重身份验证 (MFA)。

解析 / Explanation

正确答案 A,B,D,E

To secure AI systems, especially when handling sensitive data like healthcare information, it is important to implement multiple layers of security. Encrypting data, restricting access with IAM, protecting endpoints, and using MFA are all critical measures to ensure data privacy and system integrity. Disabling logging, however, is not a recommended practice as it hinders auditing and monitoring capabilities.
A. Correct. Encrypting data at rest and in transit is a critical step in securing sensitive information and is a recommended best practice for AI systems handling sensitive data.
B. Correct. Using IAM to restrict access ensures that only authorized users or roles can interact with the AI system or access associated resources, reducing the risk of unauthorized access.
C. Incorrect. Disabling logging is not recommended as logs are essential for monitoring and auditing purposes. Instead, sensitive data in logs should be masked or encrypted.
D. Correct. Endpoint protection, such as SageMaker endpoint encryption, ensures secure data communication between the client and the deployed model, protecting against potential interception.
E. Correct. Enabling MFA adds an additional layer of security to AWS accounts, reducing the risk of unauthorized access even if credentials are compromised.

为了保护人工智能系统的安全，特别是在处理医疗保健信息等敏感数据时，实施多层安全非常重要。加密数据、使用 IAM 限制访问、保护端点和使用 MFA 都是确保数据隐私和系统完整性的关键措施。但是，不建议禁用日志记录，因为它会妨碍审核和监控功能。答：正确。对静态和传输中的数据进行加密是保护敏感信息的关键步骤，也是处理敏感数据的人工智能系统推荐的最佳实践。 B、正确。使用 IAM 来限制访问，确保只有授权的用户或角色才能与 AI 系统交互或访问相关资源，从而降低未经授权的访问风险。 C、不正确。不建议禁用日志记录，因为日志对于监视和审核目的至关重要。相反，日志中的敏感数据应该被屏蔽或加密。 D、正确。端点保护（例如 SageMaker 端点加密）可确保客户端与已部署模型之间的安全数据通信，防止潜在的拦截。 E、正确。启用 MFA 为 AWS 账户增加了一层额外的安全性，即使凭证遭到泄露，也可以降低未经授权访问的风险。

You are developing an AI-powered application on AWS that uses Amazon SageMaker for model training and inference. The application handles sensitive customer data during the training process. Which combination of measures should you implement to ensure the AI system is secure?

您正在 AWS 上开发一个由 AI 支持的应用程序，该应用程序使用 Amazon SageMaker 进行模型训练和推理。该应用程序在培训过程中处理敏感的客户数据。您应该采取哪些措施组合来确保人工智能系统的安全？

  1. A

    Enable encryption for data at rest and in transit.

    对静态和传输中的数据启用加密。

  2. B

    Use SageMaker-provided default roles without modification.

    使用 SageMaker 提供的默认角色而不进行修改。

  3. C

    Implement VPC (Virtual Private Cloud) endpoints for SageMaker.

    为 SageMaker 实施 VPC（虚拟私有云）端点。

  4. D

    Use multi-factor authentication (MFA) for all IAM users managing the AI system.

    对管理 AI 系统的所有 IAM 用户使用多重身份验证 (MFA)。

  5. E

    Grant public access to the training data stored in Amazon S3 to facilitate collaboration.

    授予公众访问 Amazon S3 中存储的训练数据的权限，以促进协作。

  6. F

    Monitor and audit SageMaker activities using AWS CloudTrail.

    使用 AWS CloudTrail 监控和审计 SageMaker 活动。

解析 / Explanation

正确答案 A,C,D,F

To secure AI systems, it is crucial to implement encryption, restrict access using VPC endpoints, enforce strong authentication mechanisms like MFA, and monitor activities using services like AWS CloudTrail. Avoid practices that expose data publicly or rely on overly permissive default settings. These measures collectively safeguard sensitive data and ensure the AI system operates securely.
A. Correct. Encryption for data at rest and in transit is critical to protect sensitive customer data from unauthorized access.
B. Incorrect. Using SageMaker-provided default roles without modification can lead to overly permissive access policies, which is a security risk.
C. Correct. Using VPC endpoints for SageMaker ensures that communication remains within a private network, reducing exposure to external threats.
D. Correct. MFA enhances the security of IAM accounts by requiring a second form of authentication in addition to the password.
E. Incorrect. Granting public access to the training data stored in Amazon S3 is a significant security risk and should be avoided.
F. Correct. Monitoring and auditing SageMaker activities using AWS CloudTrail helps detect and respond to unauthorized or suspicious actions.
