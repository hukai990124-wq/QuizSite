## Question 102  `#102`

**EN** A company has developed a generative text summarization model by using Amazon Bedrock. The company will use Amazon Bedrock automatic model evaluation capabilities. Which metric should the company use to evaluate the accuracy of the model?

**中** 一家公司利用亚马逊Bedrock开发了一种生成式文本摘要模型。该公司将使用亚马逊Bedrock的自 动模型评估功能。 公司应该使用哪个指标来评估模型的准确性？

- **A.** Area Under the ROC Curve (AUC) score
  - 受试者工作特征曲线（ROC曲线）下的面积（AUC）得分
- **B.** F1 score
  - F1 值
- **C.** BERTScore
  - BERTScore
- **D.** Real world knowledge (RWK) score
  - 实际世界知识（RWK）得分

**正确答案 / Answer: `C`**

BERTScore is a metric specifically designed for evaluating the quality of text generated by models, particularly in tasks like text summarization and machine translation. It uses contextual embeddings from a pre-trained BERT model to compare generated text with reference text at the word level, making it well- suited for evaluating the accuracy of generative text summarization models. BERTScore assesses the semantic similarity between the generated text and the reference text, providing a more nuanced evaluation compared to traditional methods that focus on exact matches.

BERTScore是一种专门用于评估模型生成文本质量的指标，尤其适用于文本摘要和机器翻译等任务。它利 用预训练的BERT模型的上下文嵌入，在单词层面将生成的文本与参考文本进行比较，因此非常适合评估生 成式文本摘要模型的准确性。 BERTScore评估生成文本与参考文本之间的语义相似度，与侧重于精确匹配的传统方法相比，它能提供更 细致的评价。

## Question 103  `#103`

**EN** An Al practitioner wants to predict the classification of flowers based on petal length, petal width, sepal length, and sepal width. Which algorithm meets these requirements?

**中** 一位人工智能从业者想要根据花瓣长度、花瓣宽度、萼片长度和萼片宽度来预测花的种类。 哪种算法能满足这些要求？

- **A.** K-nearest neighbors (k-NN)
  - K近邻 (k-NN)
- **B.** K-mean
  - K均值算法
- **C.** Autoregressive Integrated Moving Average (ARIMA)
  - 自回归积分滑动平均（ARIMA）
- **D.** Linear regression
  - 线性回归

**正确答案 / Answer: `A`**

K-nearest neighbors (k-NN) is a supervised learning algorithm used for classification tasks. It works by classifying a data point based on how its features (such as petal length, petal width, sepal length, and sepal width in this case) are similar to the data points in the training set. For this problem, where the task is to classify flowers based on their features, k-NN is an appropriate choice. k-NN is simple and effective for classification problems where the decision boundary is not necessarily linear, as it looks at the closest neighbors to make predictions.

K近邻（k-NN）是一种用于分类任务的监督学习算法。它通过将数据点的特征（例如本例中的花瓣长度、 花瓣宽度、萼片长度和萼片宽度）与训练集中的数据点进行比较来对其进行分类。对于此问题，即根据特征 对花进行分类，k-NN是一个合适的选择。 k近邻算法简单有效，适用于决策边界不一定为线性的分类问题，因为它通过查看最近的邻近点来进行 预测。

  - 增加正则化参数以降低模型复杂度。
