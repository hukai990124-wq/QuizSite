PART 5 — Incomplete Sentences（101–130）

Directions: A word or phrase is missing in each of the sentences below. Four answer choices are given below each sentence. Select the best answer to complete the sentence. Then mark the letter (A), (B), (C), or (D) on your answer sheet.
101.Staff should back up their files ____ they leave the office for the holiday weekend.
  1. Aamong
  2. Bduring
  3. Cdespite
  4. Dbefore
解析 / Explanation
D. 'Before' introduces the clause showing the backup happens prior to leaving; the others cannot fit here.
102.The keynote speaker addressed the audience ____ despite the technical difficulties on stage.
  1. Aconfident
  2. Bconfidence
  3. Cconfidently
  4. Dconfiding
解析 / Explanation
C. An adverb is needed to modify the verb 'addressed', so 'confidently' is correct.
103.Mr. Salazar, ____ proposal secured the largest client this year, will lead the account.
  1. Awho
  2. Bwhom
  3. Cwhose
  4. Dwhich
解析 / Explanation
C. The possessive relative pronoun 'whose' is needed before the noun 'proposal'.
104.The commute downtown is ____ longer during the winter months than in the summer.
  1. Amuch
  2. Bmany
  3. Cmore
  4. Dmost
解析 / Explanation
A. 'Much' correctly intensifies the comparative adjective 'longer'.
105.Neither the caterer nor the florists ____ confirmed their arrival time for the gala.
  1. Ais
  2. Bwas
  3. Chave
  4. Dhas
解析 / Explanation
C. With 'neither...nor', the verb agrees with the nearer subject 'florists', which is plural, so 'have'.
106.The board agreed to ____ the launch date until the software had been fully tested.
  1. Aprevent
  2. Bcancel
  3. Cattend
  4. Dpostpone
解析 / Explanation
D. 'Postpone...until' means to delay to a later time, which fits waiting for the testing to finish.
107.The company picnic has been scheduled ____ the second Saturday of September.
  1. Ain
  2. Bon
  3. Cat
  4. Dby
解析 / Explanation
B. The preposition 'on' is used with a specific day, so 'on the second Saturday'.
108.By the time the reporters arrived, the spokesperson ____ the official statement.
  1. Areleased
  2. Bhave released
  3. Chad released
  4. Dreleases
解析 / Explanation
C. The past perfect 'had released' shows the action was completed before another past event.
109.All feedback forms should be returned ____ the close of business on Friday.
  1. Afor
  2. Buntil
  3. Csince
  4. Dby
解析 / Explanation
D. 'By' marks a deadline meaning 'no later than', whereas 'until' would imply continuing up to that point.
110.The negotiations were so ____ that the two sides needed a full week to reach an agreement.
  1. Acomplicate
  2. Bcomplicated
  3. Ccomplicating
  4. Dcomplication
解析 / Explanation
B. The '-ed' adjective 'complicated' describes the nature of the negotiations.
111.Each of the finalists ____ a portfolio of previous work to the selection panel.
  1. Apresent
  2. Bare presenting
  3. Cpresents
  4. Dwere
解析 / Explanation
C. The subject 'Each' is singular, so the singular verb 'presents' is correct.
112.The startup is recruiting a talented ____ to design its mobile banking interface.
  1. Adevelop
  2. Bdeveloper
  3. Cdeveloping
  4. Ddeveloped
解析 / Explanation
B. A noun naming a person is needed after 'a talented', so 'developer' is correct.
113.____ the instructions were clearly written, several customers still assembled the shelf incorrectly.
  1. AAlthough
  2. BBecause
  3. CSince
  4. DSo
解析 / Explanation
A. The contrast between clear instructions and errors calls for the concession word 'Although'.
114.Guests who book a suite ____ offered complimentary access to the rooftop lounge.
  1. Ais
  2. Bare
  3. Cwas
  4. Dbeing

115.The redesigned checkout page loads far more ____ than the previous version on mobile devices.
  1. Aquick
  2. Bquickly
  3. Cquicker
  4. Dquickness
解析 / Explanation

  4. Dmaking

  4. Dsecured

B. An adverb is needed to modify the participle 'stored', so 'securely' is correct.

  3. Cat
  4. Don

  3. Cobserve
  4. Dobey

125.The new dashboard permits managers ____ performance data from a single screen.
  1. Amonitor
  2. Bmonitoring
  3. Cto monitor
  4. Dmonitored

C. The pattern 'permit + object + to-infinitive' requires 'to monitor'.
126.Contractors cannot begin work on site ____ a valid permit from the city council.
  1. Aexcept
  2. Bunless
  3. Cdespite
  4. Dwithout
解析 / Explanation
D. 'Without' + noun means lacking a permit; 'unless' would require a clause, not a noun.
127.The research and marketing divisions worked ____ to bring the product to market on time.
  1. Aclose
  2. Bclosely
  3. Ccloser
  4. Dclosest

  1. Amuch

  3. Cmost
  4. Dmany

130.We will process your refund ____ the returned item has been inspected by our warehouse.
