PART 5 — Incomplete Sentences（101–130）

Directions: A word or phrase is missing in each of the sentences below. Four answer choices are given below each sentence. Select the best answer to complete the sentence. Then mark the letter (A), (B), (C), or (D) on your answer sheet.
101.All visitors must sign in at the front desk ____ entering the laboratory.
  1. Awhile
  2. Bbefore
  3. Cduring
  4. Dsince
解析 / Explanation
B. 'Before' + gerund shows the sign-in happens prior to entering; the others do not fit this time relationship.
102.The marketing team worked ____ to meet the tight product-launch deadline.
  1. Atireless
  2. Btirelessly
  3. Ctiredness
  4. Dtired
解析 / Explanation
B. An adverb is needed to modify the verb 'worked', so 'tirelessly' is correct.
103.Ms. Ford, ____ presentation impressed the investors, has been promoted to director.
  1. Awho
  2. Bwhom
  3. Cwhose
  4. Dwhich
解析 / Explanation
C. The possessive relative pronoun 'whose' is needed before the noun 'presentation'.
104.The company's profits have grown ____ over the past three years.
  1. Asteady
  2. Bsteadier
  3. Csteadily
  4. Dsteadiness
解析 / Explanation
C. An adverb is required to modify the verb 'have grown', so 'steadily' is correct.
105.Neither the supervisor nor the technicians ____ satisfied with the revised schedule.
  1. Ais
  2. Bwas
  3. Care
  4. Dhas
解析 / Explanation
C. With 'neither...nor', the verb agrees with the nearer subject 'technicians', which is plural, so 'are'.
106.Employees are encouraged to ____ any concerns directly with their supervisors.
  1. Araise
  2. Brise
  3. Carise
  4. Dlift
解析 / Explanation
A. 'Raise' takes a direct object ('raise any concerns'); 'rise' and 'arise' are intransitive.
107.The new safety regulations will take effect ____ the first of January.
  1. Ain
  2. Bon
  3. Cat
  4. Dby
解析 / Explanation
B. The preposition 'on' is used with a specific date, so 'on the first of January'.
108.By the time the guests arrived, the caterers ____ all of the food.
  1. Aprepared
  2. Bhave prepared
  3. Chad prepared
  4. Dprepare
解析 / Explanation
C. The past perfect 'had prepared' shows the action was completed before another past event.
109.The final report must be submitted ____ Friday, or the project may be delayed.
  1. Aby
  2. Buntil
  3. Csince
  4. Dfor
解析 / Explanation
A. 'By' marks a deadline meaning 'no later than', whereas 'until' would imply continuing up to that point.
110.The training session was so ____ that several attendees asked for a follow-up.
  1. Ainform
  2. Binformed
  3. Cinformative
  4. Dinformation
解析 / Explanation
C. An adjective is needed after 'so', and 'informative' describes the session.
111.Each of the branch offices ____ its own annual sales target to meet.
  1. Ahave
  2. Bare
  3. Cwere
  4. Dhas
解析 / Explanation
D. The subject 'Each' is singular, so the singular verb 'has' is correct.
112.The agency is looking for a talented ____ to manage its social media accounts.
  1. Acoordinate
  2. Bcoordinator
  3. Ccoordinated
  4. Dcoordinating
解析 / Explanation
B. A noun naming a person is needed after 'a talented', so 'coordinator' is correct.
113.The proposal was rejected ____ it exceeded the approved budget by a wide margin.
  1. Aalthough
  2. Bbecause
  3. Cdespite
  4. Dunless
解析 / Explanation
B. 'Because' introduces the reason the proposal was rejected.
114.Customers who spend over one hundred dollars ____ a complimentary gift at checkout.
  1. Areceives
  2. Breceiving
  3. Cto receive
  4. Dreceive
解析 / Explanation
D. The plural subject 'Customers' takes the plural verb 'receive'.
115.The new intern adapted to the role far more ____ than anyone had expected.
  1. Aquick
  2. Bquickly
  3. Cquicker
  4. Dquickest
解析 / Explanation
B. With 'more...than', the base adverb 'quickly' is required to form the comparison.
116.The equipment ____ in the factory is inspected every six months for safety.
  1. Ause
  2. Buses
  3. Cused
  4. Dusing
解析 / Explanation
C. The reduced passive clause 'the equipment (that is) used' requires the past participle 'used'.
117.Please make sure that all contracts are ____ signed before they are filed.
  1. Aproper
  2. Bproperly
  3. Cproperty
  4. Dpropriety
解析 / Explanation
B. An adverb is needed to modify the participle 'signed', so 'properly' is correct.
118.The success of the campaign depends ____ how well we understand our customers.
  1. Aon
  2. Bof
  3. Cat
  4. Dto
解析 / Explanation
A. The verb 'depend' is followed by the preposition 'on'.
119.____ the weather was poor, the outdoor concert still attracted a large crowd.
  1. ASo
  2. BBecause
  3. CSince
  4. DAlthough
解析 / Explanation
D. The contrast between poor weather and a large turnout calls for the concession word 'Although'.
120.This printer model is far more reliable than ____ the office used last year.
  1. Aone
  2. Bthe one
  3. Cthat ones
  4. Dthose one
解析 / Explanation
B. 'The one' refers back to a single printer model, matching 'This printer model'.
121.The auditor asked all staff to ____ with the new reporting procedures.
  1. Acomply
  2. Badhere
  3. Cobserve
  4. Dobey
解析 / Explanation
A. 'Comply' pairs with 'with'; 'adhere' would take 'to', and 'observe' and 'obey' take a direct object.
122.The projector will be ____ by a technician before the presentation begins.
  1. Aset
  2. Bsetting
  3. Cto set
  4. Dset up
解析 / Explanation
D. The phrasal verb 'set up' completes the passive structure 'will be set up'.
123.Ticket sales this month were higher than in ____ month this year.
  1. Aany other
  2. Bother any
  3. Cthe other any
  4. Dany others
解析 / Explanation
A. 'Any other' correctly compares this month against every remaining month.
124.The company reported a significant ____ in online orders during the holiday season.
  1. Aincreasing
  2. Bincreased
  3. Cincreasingly
  4. Dincrease
解析 / Explanation
D. A singular noun is needed after 'a significant', so 'increase' is correct.
125.The new software allows managers ____ employee schedules from their phones.
  1. Aadjust
  2. Badjusting
  3. Cadjusted
  4. Dto adjust
解析 / Explanation
D. The pattern 'allow + object + to-infinitive' requires 'to adjust'.
126.Visitors are not permitted to enter the warehouse floor ____ a safety helmet.
  1. Awithout
  2. Bunless
  3. Cdespite
  4. Dexcept
解析 / Explanation
A. 'Without' + noun means lacking a helmet; 'unless' would need a clause, not a noun.
127.The two departments must work together ____ to complete the merger smoothly.
  1. Aclose
  2. Bclosest
  3. Ccloser
  4. Dclosely
解析 / Explanation
D. An adverb is needed to modify 'work together', so 'closely' is correct.
128.____ arriving at the airport, please proceed directly to the check-in counter.
  1. AUpon
  2. BDuring
  3. CWhile
  4. DSince
解析 / Explanation
A. 'Upon arriving' means immediately after arriving, which fits the instruction.
129.Of all the applicants, Ms. Reyes had the ____ experience in project management.
  1. Amuch
  2. Bmore
  3. Cmost
  4. Dmany
解析 / Explanation
C. Comparing one person against the whole group requires the superlative, so 'the most'.
130.The shipment will be delivered ____ it clears the customs inspection.
  1. Ain case
  2. Bin order to
  3. Cso that
  4. Das soon as
解析 / Explanation
D. 'As soon as' introduces the time at which the delivery will happen.
