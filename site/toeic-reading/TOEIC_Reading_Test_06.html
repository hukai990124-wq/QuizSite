PART 5 — Incomplete Sentences（101–130）

Directions: A word or phrase is missing in each of the sentences below. Four answer choices are given below each sentence. Select the best answer to complete the sentence. Then mark the letter (A), (B), (C), or (D) on your answer sheet.
101.Employees are asked to switch off their monitors ____ leaving the building each evening.
  1. Aupon
  2. Bamong
  3. Cdespite
  4. Dbetween
解析 / Explanation
A. 'Upon leaving' means at the moment of leaving, which fits the instruction; the others cannot introduce this action.
102.The technician explained the safety procedure ____ so that everyone could follow along.
  1. Aclear
  2. Bclearly
  3. Cclearness
  4. Dclearing
解析 / Explanation
B. An adverb is needed to modify the verb 'explained', so 'clearly' is correct.
103.Ms. Ahmadi, ____ department exceeded its targets, was invited to present at headquarters.
  1. Awho
  2. Bwhom
  3. Cwhose
  4. Dwhich
解析 / Explanation
C. The possessive relative pronoun 'whose' is needed before the noun 'department'.
104.The updated model is considerably ____ to operate than the one it replaced.
  1. Aeasy
  2. Beasily
  3. Ceasiest
  4. Deasier
解析 / Explanation
D. The comparison with 'than' requires the comparative form 'easier'.
105.Neither the editor nor the writers ____ satisfied with the proposed cover design.
  1. Ais
  2. Bwas
  3. Cwere
  4. Dhas
解析 / Explanation
C. With 'neither...nor', the verb agrees with the nearer subject 'writers', which is plural, so 'were'.
106.The airline offered passengers a voucher to ____ for the lengthy delay.
  1. Acompensate
  2. Breward
  3. Crefund
  4. Dreimburse
解析 / Explanation
A. 'Compensate for' means to make up for something negative such as a delay; the others do not fit this pattern.
107.The grand opening of the flagship store is planned ____ the middle of October.
  1. Ain
  2. Bon
  3. Cat
  4. Dby
解析 / Explanation
A. The preposition 'in' is used with a month or period, so 'in the middle of October'.
108.By the time the shift ended, the volunteers ____ more than three hundred meals.
  1. Aserved
  2. Bhave served
  3. Chad served
  4. Dserve
解析 / Explanation
C. The past perfect 'had served' shows the action was completed before another past event.
109.Registrations for the workshop must be completed ____ the end of the week.
  1. Aby
  2. Buntil
  3. Csince
  4. Dfor
解析 / Explanation
A. 'By' marks a deadline meaning 'no later than', whereas 'until' would imply continuing up to that point.
110.The lecture on market trends was so ____ that the audience took extensive notes.
  1. Ainform
  2. Binformed
  3. Cinformative
  4. Dinformation
解析 / Explanation
C. An adjective is needed after 'so', and 'informative' describes the lecture.
111.Each of the departments ____ responsible for preparing its own quarterly forecast.
  1. Aare
  2. Bhave
  3. Cis
  4. Dwere
解析 / Explanation
C. The subject 'Each' is singular, so the singular verb 'is' is correct.
112.The airline is hiring a qualified ____ to manage its regional flight schedules.
  1. Acoordinate
  2. Bcoordinator
  3. Ccoordinated
  4. Dcoordinating
解析 / Explanation
B. A noun naming a person is needed after 'a qualified', so 'coordinator' is correct.
113.The delivery was refused ____ the packaging showed clear signs of damage.
  1. Aunless
  2. Balthough
  3. Cdespite
  4. Dbecause
解析 / Explanation
D. 'Because' introduces the reason the delivery was refused.
114.Members who renew early ____ granted access to the exclusive online library.
  1. Ais
  2. Bare
  3. Cwas
  4. Dbeing
解析 / Explanation
B. The plural subject 'Members' takes the plural passive verb 'are granted'.
115.The upgraded engine runs far more ____ than the standard model under heavy loads.
  1. Aefficient
  2. Befficiently
  3. Cefficienter
  4. Defficiency
解析 / Explanation
B. With 'more...than', the base adverb 'efficiently' is required to modify 'runs'.
116.The comments ____ during the review will be incorporated into the next draft.
  1. Acollect
  2. Bcollects
  3. Ccollected
  4. Dcollecting
解析 / Explanation
C. The reduced passive clause 'the comments (that were) collected' requires the past participle 'collected'.
117.Please make sure the invoices are ____ labeled before they are sent to accounting.
  1. Aaccurate
  2. Baccurately
  3. Caccuracy
  4. Daccurateness
解析 / Explanation
B. An adverb is needed to modify the participle 'labeled', so 'accurately' is correct.
118.The final approval of the design rests ____ the senior architect on the project.
  1. Ato
  2. Bof
  3. Cat
  4. Dwith
解析 / Explanation
D. 'Rest with someone' means to be that person's responsibility, so 'with' is correct.
119.____ the store had advertised the sale for weeks, very few customers showed up.
  1. AAlthough
  2. BBecause
  3. CSince
  4. DSo

120.The current accounting system is much slower than ____ the firm installed years ago.
  1. Aone
  2. Bthe one
  3. Cthat ones
  4. Dthose one
解析 / Explanation
B. 'The one' refers back to a single system, matching 'the current accounting system'.
121.Every contractor is required to ____ to the confidentiality terms of the agreement.
  1. Acomply
  2. Badhere
  3. Cobserve
  4. Dfollow
解析 / Explanation
B. 'Adhere' pairs with 'to'; 'comply' would take 'with', and the others take a direct object without 'to'.
122.The trade-show booth will be ____ by the crew the night before the doors open.
  1. Aset
  2. Bsetting
  3. Cto set
  4. Dset up

  1. Aany others

  4. Dany other

124.The survey revealed a marked ____ in customer satisfaction after the redesign.

  4. Dimprovement

D. A singular noun is needed after 'a marked', so 'improvement' is correct.
125.The new plan enables employees ____ their vacation days entirely online.
  1. Arequest
  2. Brequesting
  3. Crequested
  4. Dto request
解析 / Explanation
D. The pattern 'enable + object + to-infinitive' requires 'to request'.
126.Visitors may not photograph the exhibits ____ prior consent from the gallery.
  1. Aexcept
  2. Bunless
  3. Cdespite
  4. Dwithout
解析 / Explanation
D. 'Without' + noun means lacking consent; 'unless' would require a clause, not a noun.
127.The sales and support teams collaborated ____ to resolve the client's complaint.
  1. Aswift
  2. Bswiftly
  3. Cswifter
  4. Dswiftest
解析 / Explanation
B. An adverb is needed to modify 'collaborated', so 'swiftly' is correct.
128.____ submitting the application, please double-check that all fields are complete.
  1. ABefore
  2. BDuring
  3. CWhile
  4. DSince

129.Among the three suppliers evaluated, this one offered the ____ favorable payment terms.
  1. Amuch
  2. Bmore
  3. Cmost
  4. Dmany
解析 / Explanation
C. Comparing one supplier against the whole group requires the superlative, so 'the most'.
130.We will dispatch your order ____ the payment has cleared our system.
  1. Aas soon as

  4. Din case
