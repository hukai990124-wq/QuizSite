PART 5 — Incomplete Sentences（101–130）

Directions: A word or phrase is missing in each of the sentences below. Four answer choices are given below each sentence. Select the best answer to complete the sentence. Then mark the letter (A), (B), (C), or (D) on your answer sheet.
101.The warehouse staff must wear protective gloves ____ handling any of the chemical containers.
  1. Awhenever
  2. Bdespite
  3. Calthough
  4. Dhowever
解析 / Explanation
A. 'Whenever' + gerund states the condition under which gloves are required; the others cannot introduce this time relationship.
102.The renovation of the lobby was completed ____ ahead of the original schedule.
  1. Aconsider
  2. Bconsiderable
  3. Cconsiderably
  4. Dconsideration
解析 / Explanation
C. An adverb is needed to modify 'ahead', so 'considerably' is correct.
103.Dr. Feng, ____ research on battery efficiency won a national prize, will address the conference.
  1. Awho
  2. Bwhom
  3. Cwhose
  4. Dwhich
解析 / Explanation
C. The possessive relative pronoun 'whose' is needed before the noun 'research'.
104.The revised return policy is ____ generous than the one it replaced last year.
  1. Amuch
  2. Bmore
  3. Cmost
  4. Dvery
解析 / Explanation
B. The word 'than' signals a comparison, so the comparative 'more generous' is required.
105.Neither the receptionist nor the interns ____ trained to operate the new phone system yet.
  1. Ais
  2. Bwas
  3. Care
  4. Dhas
解析 / Explanation
C. With 'neither...nor', the verb agrees with the nearer subject 'interns', which is plural, so 'are'.
106.The negotiators reached a compromise that both parties found ____ acceptable.
  1. Amutual
  2. Bmutualness
  3. Cmutuality
  4. Dmutually
解析 / Explanation
D. An adverb is needed to modify the adjective 'acceptable', so 'mutually' is correct.
107.The annual shareholders' meeting will be held ____ the auditorium on the ground floor.
  1. Aby
  2. Bon
  3. Cat
  4. Din
解析 / Explanation
D. The preposition 'in' is used with an enclosed space such as an auditorium.
108.By the time the inspector arrived, the crew ____ the scaffolding around the building.
  1. Aassembled
  2. Bhave assembled
  3. Chad assembled
  4. Dassemble
解析 / Explanation
C. The past perfect 'had assembled' shows the action was completed before another past event.
109.The signed agreements must reach the legal office ____ noon on Thursday.
  1. Aby
  2. Buntil
  3. Csince
  4. Dfor
解析 / Explanation
A. 'By' marks a deadline meaning 'no later than', whereas 'until' would imply continuing up to that point.
110.The audience found the demonstration so ____ that many stayed to ask questions afterward.
  1. Afascinate
  2. Bfascinated
  3. Cfascinating
  4. Dfascination
解析 / Explanation
C. The '-ing' adjective 'fascinating' describes something that causes fascination, which fits the demonstration.
111.Each of the training modules ____ a short quiz that must be passed before continuing.
  1. Ainclude
  2. Bare
  3. Cincludes
  4. Dwere
解析 / Explanation
C. The subject 'Each' is singular, so the singular verb 'includes' is correct.
112.The publisher is searching for a skilled ____ to review its scientific manuscripts.
  1. Aedit
  2. Bedited
  3. Cediting
  4. Deditor
解析 / Explanation
D. A noun naming a person is needed after 'a skilled', so 'editor' is correct.
113.The outdoor market was moved indoors ____ the forecast predicted heavy rain all weekend.
  1. Abecause
  2. Balthough
  3. Cdespite
  4. Dunless
解析 / Explanation
A. 'Because' introduces the reason the market was moved indoors.
114.Passengers whose flights are delayed ____ entitled to a complimentary meal voucher.
  1. Ais
  2. Bare
  3. Cwas
  4. Dbeing
解析 / Explanation
B. The plural subject 'Passengers' takes the plural verb 'are'.
115.The updated prototype performed far more ____ than the earlier version in every test.
  1. Areliable
  2. Breliably
  3. Creliabler
  4. Dreliability
解析 / Explanation
B. With 'more...than', the base adverb 'reliably' is required to modify 'performed'.
116.The samples ____ from the production line are tested for defects before shipping.
  1. Aselect
  2. Bselects
  3. Cselected
  4. Dselecting
解析 / Explanation
C. The reduced passive clause 'the samples (that are) selected' requires the past participle 'selected'.
117.Please make certain the alarm system is ____ activated when the last employee leaves.
  1. Acorrect
  2. Bcorrectly
  3. Ccorrection
  4. Dcorrected
解析 / Explanation
B. An adverb is needed to modify 'activated', so 'correctly' is correct.
118.The outcome of the merger relies ____ approval from the regulatory authorities.
  1. Ato
  2. Bof
  3. Cat
  4. Don
解析 / Explanation
D. The verb 'rely' is followed by the preposition 'on'.
119.____ the budget was approved months ago, work on the project has not yet begun.
  1. AAlthough
  2. BBecause
  3. CSince
  4. DSo
解析 / Explanation
A. The contrast between an approved budget and stalled work calls for the concession word 'Although'.
120.The current logistics provider is far more efficient than ____ the firm used previously.
  1. Aone
  2. Bthe one
  3. Cthat ones
  4. Dthose one
解析 / Explanation
B. 'The one' refers back to a single provider, matching 'the current logistics provider'.
121.Contractors are expected to ____ to the site's strict health and safety standards.
  1. Acomply
  2. Badhere
  3. Cobserve
  4. Dfollow
解析 / Explanation
B. 'Adhere' pairs with 'to'; 'comply' would take 'with', and the others take a direct object without 'to'.
122.The exhibition stand will be ____ by the design team the evening before the fair.
  1. Atake
  2. Btaking
  3. Cto take
  4. Dtaken down
解析 / Explanation
D. The phrasal verb 'taken down' completes the passive structure 'will be taken down'.
123.This branch processes more loan applications than ____ office in the network.
  1. Aany others
  2. Bother any
  3. Cthe other any
  4. Dany other
解析 / Explanation
D. 'Any other' correctly compares this branch against every remaining office.
124.Management reported a substantial ____ in productivity after the new software was installed.
  1. Aimprove
  2. Bimproved
  3. Cimproving
  4. Dimprovement
解析 / Explanation
D. A singular noun is needed after 'a substantial', so 'improvement' is correct.
125.The updated portal enables customers ____ their invoices without contacting support.
  1. Adownload
  2. Bdownloading
  3. Cdownloaded
  4. Dto download
解析 / Explanation
D. The pattern 'enable + object + to-infinitive' requires 'to download'.
126.No employee may enter the archive vault ____ written permission from a supervisor.
  1. Awithout
  2. Bunless
  3. Cdespite
  4. Dexcept
解析 / Explanation
A. 'Without' + noun means lacking permission; 'unless' would require a clause, not a noun.
127.The finance and audit teams cooperated ____ to finalize the accounts before the deadline.
  1. Aclose
  2. Bclosely
  3. Ccloser
  4. Dclosest
解析 / Explanation
B. An adverb is needed to modify 'cooperated', and 'cooperate closely' is the natural collocation, so 'closely' is correct.
128.____ completing the online form, applicants will receive a confirmation number immediately.
  1. AUpon
  2. BDuring
  3. CWhile
  4. DSince
解析 / Explanation
A. 'Upon completing' means immediately after completing, which fits the instruction.
129.Among all the vendors invited to bid, theirs was the ____ competitive quotation by far.
  1. Amuch
  2. Bmore
  3. Cmost
  4. Dmany
解析 / Explanation
C. Comparing one vendor against the whole group requires the superlative, so 'the most'.
130.We will release the payment ____ the delivery has been confirmed by the receiving department.
  1. Aonce
  2. Bin order to
  3. Cso that
  4. Din case
解析 / Explanation
A. 'Once' introduces the time at which the payment will be released.
