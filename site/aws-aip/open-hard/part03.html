  1. A

    Store records in Amazon S3 with Object Lock in compliance mode for the required retention period.

B. 策略请求在技术上并不能阻止修改或删除。

C. 内存存储是易失性的，并且不提供持久、不可变的保留。

D. 版本控制会保留以前的版本，但不会阻止删除或强制执行合规性保留锁定。

Stored embeddings and invocation logs contain sensitive business data, and the security team must control and audit the encryption keys used to protect them at rest. Which approach should they adopt?

存储的嵌入和调用日志包含敏感的业务数据，安全团队必须控制和审核用于静态保护它们的加密密钥。他们应该采取哪种方法？

  1. A

    Encrypt the data with AWS KMS customer managed keys and restrict and audit key usage via key policies and CloudTrail.

    使用 AWS KMS 客户管理的密钥加密数据，并通过密钥策略和 CloudTrail 限制和审核密钥的使用。

  2. B

    Leave the data unencrypted to simplify access.

    保持数据未加密以简化访问。

  3. C

    Use a single shared password stored in code.

    使用存储在代码中的单个共享密码。

  4. D

    Make the storage public so keys are unnecessary.

    将存储公开，这样就不需要密钥了。

解析 / Explanation

正确答案 / Answer: A

A. Customer managed KMS keys give the team control over rotation and access, and CloudTrail records key usage for auditing.

B. Unencrypted sensitive data fails the data-protection requirement.

C. A hard-coded shared secret is insecure and not an auditable managed key.

D. Public storage exposes the sensitive data and is the opposite of the requirement.

A. 客户管理的 KMS 密钥使团队能够控制轮换和访问，CloudTrail 记录密钥使用情况以供审核。

B. 未加密的敏感数据不符合数据保护要求。

C. 硬编码的共享密钥是不安全的，并且不是可审计的托管密钥。

D. 公共存储暴露了敏感数据，与要求相反。
